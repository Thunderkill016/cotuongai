# Product milestones

## M1 — One complete learning loop

Status: engineering implementation complete; live-browser acceptance pending.

Learner can inspect a position, choose candidate moves, make a legal move, receive bounded feedback, reveal progressively clearer hints, inspect engine analysis explicitly, retry, and retain local attempt history.

## M2 — Adaptive practice

- mistake taxonomy backed by deterministic/engine evidence,
- per-skill practice history,
- retrieval queue for prior mistakes,
- session composition from warm-up -> concept -> independent attempt -> review,
- no Elo/mastery claims until validated.

## M3 — Real curriculum

- larger position corpus with source/provenance,
- expert review workflow,
- opening/endgame modules,
- learner studies that measure delayed transfer rather than immediate completion.

## M4 — 3D presentation experiment

Build 3D as an optional view, never as the rules layer. Compare against 2D for piece recognition, move selection accuracy, time-on-task and perceived clarity. Keep it only if it helps or at least does not harm learning/readability.

## M5 — Accounts / sync / deployment hardening

Only after the local trainer proves useful: authenticated progress, server persistence, abuse controls, deployment telemetry and multi-device sync.
